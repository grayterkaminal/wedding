# Михаил и Екатерина · 12 декабря 2026

Новая версия свадебного приглашения. Обычные HTML, CSS и JavaScript, без сборки и внешних зависимостей. Все изображения и шрифты находятся в проекте. Интернет нужен только для перехода в Telegram и на карту.

## Быстро посмотреть

1. Распакуйте архив целиком.
2. Откройте `index.html` в браузере или папку проекта в VS Code.

Так можно посмотреть дизайн, анимации, палитры и форму. Чтобы анкета действительно сохраняла ответы, запустите сервер по инструкции ниже. VS Code Live Server показывает дизайн, но не принимает анкеты.

## Запустить с рабочей анкетой

Нужен Node.js версии 18 или новее. В терминале VS Code, открытом в папке проекта:

```bash
node server.mjs
```

Откройте `http://127.0.0.1:3000`. Установка пакетов и команда `npm install` не нужны. На Windows можно также запустить `start.cmd` и открыть адрес, напечатанный в окне.

После отправки первой анкеты ответы находятся в папке `responses`:

- `responses.csv` — таблица для Excel (UTF-8 с BOM, разделитель — точка с запятой);
- `responses.jsonl` — основной журнал ответов. CSV восстанавливается из него при перезапуске сервера.

Одна анкета рассчитана на одного гостя. Напитки можно выбирать несколько, горячее — одно. Если человек не придёт, вопросы о напитках и еде скрываются. Имя и решение о присутствии обязательны; предпочтения можно оставить пустыми. Форма показывает успех только после записи на сервер. В случае ошибки ответы остаются в форме, а гостю доступно копирование для личной передачи организатору.

Тестовые ответы в архив не включены. Сервер не публикует папку с ответами и свой исходный код через HTTP.

## Публикация

Сайт ещё не опубликован. Для общего сбора ответов сервер должен работать на хостинге с Node.js и постоянным диском. При копировании только HTML/CSS/JS на статический хостинг анкеты сохраняться не будут. Тот же дизайн можно подключить к другому обработчику, указав `rsvpEndpoint` в `js/config.js`; ожидается POST JSON и ответ `{ "ok": true }` после успешной записи.

Параметры сервера:

- `PORT` — порт, по умолчанию `3000`;
- `HOST` — адрес прослушивания, локально `127.0.0.1`; на хостинге обычно `0.0.0.0`;
- `DATA_DIR` — каталог на постоянном диске для ответов.

Для публикации подключите HTTPS средствами хостинга. Ответы выдаются владельцу через файлы на сервере; административной страницы и автоматической отправки анкет в Telegram в этой версии нет. Общий чат предназначен для гостей и фотографий, предпочтения из анкеты туда не публикуются. Не размещайте `responses` внутри общедоступной папки при переносе на другой сервер.

## Визуальная версия

Светлая ледяная гамма, мягкий фон с ветвями и далёкими арками, отдельная мобильная композиция, хрустальная фотографическая фактура. Декор поддерживает текст. Фотография пары и портреты контактов взяты из вашего проекта без художественного редактирования. Тексты немного сокращены для первой визуальной версии и готовы к дальнейшей редактуре.

Снег работает только на первом экране; за пределами экрана анимационный цикл останавливается. Есть кнопка паузы и поддержка системной настройки уменьшения движения. Появление блоков не скрывает содержание при выключенном JavaScript.

Проверено в Chromium: ширины 320, 390, 768 и 1440 пикселей, календарь, контакты, ссылки чата, клавиатурное переключение палитр, отправка и запись анкет, отказ от присутствия, защита от повторной записи одного ответа, отсутствие доступа к файлам ответов через HTTP, поведение формы при открытии с диска. Проверка на настоящем iPhone/Safari пока не выполнялась.
