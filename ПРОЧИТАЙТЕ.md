Новая версия свадебного приглашения. Обычные HTML, CSS и JavaScript, без сборки и внешних зависимостей. Все изображения и шрифты находятся в проекте. На опубликованном сайте интернет нужен для отправки анкеты, перехода в Telegram и на карту.

## Быстро посмотреть

1. Распакуйте архив целиком.
2. Откройте `index.html` в браузере или папку проекта в VS Code.

Так можно посмотреть дизайн, анимации, палитры и форму. Чтобы анкета действительно сохраняла ответы, запустите сервер по инструкции ниже. VS Code Live Server показывает дизайн, но не принимает анкеты.

## Запустить с рабочей анкетой

Нужен Node.js версии 18 или новее. В терминале VS Code, открытом в папке проекта:

```bash
node server.mjs
```

Откройте `http://127.0.0.1:3000`. Установка пакетов и команда `npm install` не нужны. На Windows можно также запустить `start.cmd` и открыть адрес, напечатанный в окне.

После отправки первой анкеты ответы находятся в папке `responses`:

- `responses.csv` — таблица для Excel (UTF-8 с BOM, разделитель — точка с запятой);
- `responses.jsonl` — основной журнал ответов. CSV восстанавливается из него при перезапуске сервера.

Одна анкета рассчитана на одного гостя. Напитки можно выбирать несколько, горячее — одно. Если человек не придет, вопросы о напитках и еде скрываются. Имя и решение о присутствии обязательны; предпочтения можно оставить пустыми. Форма показывает успех после подтверждения сервера; при настроенной Google-интеграции сервер подтверждает ответ только после успешной записи в Google Таблицу. Локальные JSONL и CSV служат резервной копией. В случае ошибки ответы остаются в форме, а гостю доступно копирование для личной передачи организатору.

Тестовые ответы в архив не включены. Сервер не публикует папку с ответами и свой исходный код через HTTP.

## Публикация

Сайт уже развернут с backend и Google-интеграцией. При обновлении фронтенда сохраняйте существующие настройки хостинга и переменные окружения. Для локальных резервных копий нужен постоянный диск. При копировании только HTML/CSS/JS на статический хостинг анкеты сохраняться не будут. Тот же дизайн можно подключить к другому обработчику, указав `rsvpEndpoint` в `js/config.js`; ожидается POST JSON и ответ `{ "ok": true }` после успешной записи.

Параметры сервера:

- `PORT` — порт, по умолчанию `3000`;
- `HOST` — адрес прослушивания, локально `127.0.0.1`; на хостинге обычно `0.0.0.0`;
- `DATA_DIR` — каталог на постоянном диске для ответов;
- `GOOGLE_RSVP_URL` — адрес действующего Google-обработчика;
- `RSVP_API_TOKEN` — секретный токен, согласованный с Google-обработчиком. Хранится только в окружении сервера.

Без обеих Google-переменных сервер работает локально. Если задана только одна, отправка возвращает ошибку: для Google-интеграции нужны обе. Не переносите токен или адрес обработчика во фронтенд.

Для публикации подключите HTTPS средствами хостинга. Ответы поступают владельцу в Google Таблицу, а резервные копии сохраняются на сервере. Административной страницы и автоматической отправки анкет в Telegram нет. Общий чат предназначен для гостей и фотографий, предпочтения из анкеты туда не публикуются. Не размещайте `responses` внутри общедоступной папки при переносе на другой сервер.

## Визуальная версия

Светлая ледяная гамма, мягкий фон с ветвями и далекими арками, отдельная мобильная композиция, хрустальная фотографическая фактура. Декор поддерживает текст. Фотография пары и портреты контактов взяты из вашего проекта без художественного редактирования. Тексты немного сокращены для первой визуальной версии и готовы к дальнейшей редактуре.

Снег работает только на первом экране; за пределами экрана анимационный цикл останавливается. Анимация запускается автоматически, без кнопки паузы; системная настройка уменьшения движения по-прежнему учитывается. Появление блоков не скрывает содержание при выключенном JavaScript.

В блоках даты, настроения, программы и чата мягко движется свет и мерцают редкие хрустальные блики. Эффекты работают только в видимых разделах и останавливаются в скрытой вкладке. На компьютере зимний фон слегка следует за курсором; текст остается неподвижным. Системная настройка уменьшения движения отключает эти эффекты, на сенсорных устройствах движения за курсором нет.

Проверено после визуальной доработки в Chromium: ширины 320, 390, 768, 1024 и 1440 пикселей, отсутствие горизонтального переполнения, контакты и телефоны, точный тайминг, автоматический снег, переключение палитр с клавиатуры, раскрытие оттенков. Сценарии анкеты (черновик, ошибка, повторная попытка с тем же ID, успех, следующий гость и отказ от присутствия) проверены с подменой ответа API, без записей в рабочую Google Таблицу.

`server.mjs` сохранен без изменений. Блок логики анкеты во фронтенде совпадает с предыдущей версией; исправлено только написание буквы е в сообщении об ошибке и комментарии. Адрес endpoint и варианты еды не изменены. В список напитков добавлены текила, ром и виски; сервер принимает их через общую конфигурацию. На настоящем iPhone/Safari эта итерация не проверялась.
